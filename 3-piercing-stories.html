5 เรื่องเล่ารอจิกอันดับ 1 - อ่านบนเว็บได้เลย ไม่ต้องโหลด PDF/TXT

ทั้ง 5 เรื่องเป็นเรื่องเดียวกัน: ไม่มีเรามาแต่แรก

1. หลวงตาณรงค์ศักดิ์: ไม่มีผู้ยึดมาแต่แรก

ไม่มีผู้ยึดมาแต่แรก ไม่มีผู้ปล่อยวางมาแต่แรก เมื่อไม่มีผู้ยึด ใยต้องปล่อยวาง

ผ่านตลอด ไม่มีไฟเขียวไฟแดง Set Zero + Pop-up + Jump Start เราเป็นผ้า ผ้าที่โยนขึ้นแล้วเปลี่ยนไม่ได้ ไม่มีผู้ไป take ownership

2. หลวงปู่ลี: สักแต่ว่า - พาหิยสูตร

ดูกรพาหิยะ ในกาลใดแล เมื่อท่านเห็นจักเป็นสักว่าเห็น เมื่อฟังจักเป็นสักว่าฟัง เมื่อทราบจักเป็นสักว่าทราบ เมื่อรู้แจ้งจักเป็นสักว่ารู้แจ้ง ในกาลนั้น ท่านย่อมไม่มี ในกาลใดท่านไม่มี ในกาลนั้นท่านย่อมไม่มีในโลกนี้ ย่อมไม่มีในโลกหน้า ย่อมไม่มีในระหว่างแห่งโลกทั้งสอง นั่นแลคือที่สุดแห่งทุกข์

เลิกเสี้ยววินาที -> เห็น 1 โผล่จาก 0 -> เห็น 1 เกิดดับ -> Set Zero ใหม่

3. เรื่องเล่าหลวงตา: เมื่อก่อนแตกต่างทุกวันนี้ไม่แตกต่าง เพราะไม่มีเรามาแต่แรก

เมื่อก่อนเห็นว่าพระนิพพานแตกต่างจากเรา ทุกวันนี้ไม่แตกต่าง เพราะไม่มีเรามาแต่แรก

4. เว่ยหล่าง: เมื่อกระจกไม่มี ฝุ่นจะเกาะอะไร? - จาก gonghoog.com - อ่านบนเว็บได้เลย

โพธิ์เดิมไม่มีต้น กระจกใสก็ไม่มี เมื่อทุกสิ่งว่างเปล่าแล้ว ฝุ่นจะลงจับอะไร?

จิตเดิมแท้ของเราซึ่งเป็นเมล็ดพืชหรือแก่นของการตรัสรู้นั้น เป็นของบริสุทธิ์ตามธรรมชาติ ต้องอาศัยจิตเดิมแท้ นี้เท่านั้น มนุษย์เราจึงจะเข้าถึงความเป็นพุทธะได้โดยตรง

ที่มา: gonghoog.com - สูตรของเว่ยหล่าง - เปิดอ่านบนเว็บได้เลย 2715 บรรทัด

5. หลวงปู่ดูลย์ 3 เล่ม 502 หน้า: จิตเห็นจิตเป็นมรรค / จิตหนึ่งคือพุทธะ - จาก nkgen.com - อ่านบนเว็บได้เลย

จิตที่ส่งออกนอกเป็นสมุทัย ผลของจิตที่ส่งออกนอกเป็นทุกข์ จิตเห็นจิตเป็นมรรค ผลของจิตเห็นจิตเป็นนิโรธ

จิตหนึ่งนี้เท่านั้นเป็น พุทธะ พระพุทธเจ้าทั้งปวงและสัตว์โลกทั้งสิ้น ไม่ได้เป็นอะไรเลย นอกจากเป็นเพียง จิตหนึ่ง One Mind นอกจากจิตหนึ่ง นี้แล้ว มิได้มีอะไรตั้งอยู่เลย

ตัวจิตแท้ๆไม่ได้เคลื่อนไหว ที่เคลื่อนคือกิริยา คลื่นกับน้ำ เมื่อจิตออกไปยึดอารมณ์ ยึดมั่นถือมั่น ผูกพัน หวั่นไหว คือสังขารปรุงแต่ง จิตพ้นจากอารมณ์ พ้นจากการปรุงแต่ง ทุกข์ตั้งอยู่ไม่ได้ นั่นคือพระแท้
