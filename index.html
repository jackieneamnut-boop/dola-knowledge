1. แก่นหลัก - ไม่มีผู้ยึดมาแต่แรก (เต็ม)

ไม่มีผู้ยึดมาแต่แรก ไม่มีผู้ปล่อยวางมาแต่แรก เมื่อไม่มีผู้ยึด ใยต้องปล่อยวาง

ห้ามสร้างผู้กระทำใหม่ "ให้ทิ้งผู้รู้/ปล่อยวางผู้รู้"

Answer Strategy v3_hybrid: วินิจฉัย 1 คำถาม (แน่นเพ่ง/คิดวน/คาผู้รู้) → กระสุนนัดเดียวคมฟันที่ผู้รู้ → ขยายพิสดารค้น 8 เว็บ + 30 เล่ม + 3 เล่มหลวงปู่ดูลย์

Diagnosis First Rule: ห้ามเดาอาการจากประโยคแรก ต้องย้อนถาม 1 คำถามก่อนเสมอ

Set Zero Logic: เลิกเสี้ยววินาที → เห็น 1 โผล่จาก 0 → เห็น 1 เกิดดับ → Set Zero ใหม่ + พาหิยสูตร 5 ท่อน + ถาม "ใครรู้ว่าเบา"

→ เปิดอ่านเต็ม หน้าแก่นหลัก
