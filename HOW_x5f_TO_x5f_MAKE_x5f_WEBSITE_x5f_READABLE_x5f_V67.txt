## วิธีเอาไปทำเว็บไซต์จริง - 3 ทางเลือก - อ่านบนหน้าเว็บได้เลย ไม่ต้องโหลด PDF/TXT

### ทางเลือกที่ 1: GitHub Pages - ฟรี 100% - แนะนำ - อ่านบนเว็บได้เลย

#### ขั้นตอนที่ 1: สร้าง GitHub Account
1. ไป https://github.com/
2. สมัครฟรี
3. ยืนยันอีเมล

#### ขั้นตอนที่ 2: สร้าง Repository
1. กด New repository
2. ชื่อ: dola-knowledge
3. เลือก Public
4. กด Create repository

#### ขั้นตอนที่ 3: อัพโหลดไฟล์เว็บไซต์ที่ผมทำให้
1. ใน repository กด Add file -> Upload files
2. อัพโหลดไฟล์ทั้งหมดจาก /mnt/data/dola-website/ - ลากทั้งหมดขึ้นไป
3. กด Commit changes

#### ขั้นตอนที่ 4: เปิด GitHub Pages
1. ไป Settings -> Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. กด Save
5. รอ 2-3 นาที จะได้ URL: https://yourusername.github.io/dola-knowledge/
6. เปิด URL นี้ จะเห็นหน้าแรก อ่านบนเว็บได้เลย ไม่ต้องโหลด PDF/TXT

#### ขั้นตอนที่ 5: ทดสอบว่า AI ค้นได้
1. บอกผมว่า: โหลดเว็บทั้งหมด 9 เว็บ etipitaka.com + 84000.org + anakame.com + Luangta.com + luangtanarongsak.org + dhamma.com + gonghoog.com + nkgen.com + yourusername.github.io/dola-knowledge/ + โหลด MINI V6.7
2. ผมจะค้นด้วย site:yourusername.github.io/dola-knowledge/ ได้เหมือนค้น 84000.org

## ทำไมต้องอ่านบนหน้าเว็บได้เลย ไม่ต้องโหลด PDF/TXT?

ตามที่ท่านบอก: คนไปโหลด pdf หรือ txt มาอ่านเองไม่ได้เพราะเคยลองแล้ว

- PDF/TXT ต้องโหลดแล้วเปิดด้วยโปรแกรมอื่น บางคนเปิดไม่ได้
- HTML อ่านบนหน้าเว็บได้เลย เปิด browser ก็อ่านได้ทันที ไม่ต้องโหลด
- AI ก็ค้นได้ด้วย site:your-website.com
